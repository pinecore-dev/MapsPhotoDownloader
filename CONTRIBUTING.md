# Contributing

Thank you for your interest in Maps Photo Downloader.

- Open an issue describing a reproducible bug or proposed improvement.
- Keep changes focused and preserve existing language translations.
- Test the extension in Chrome via `chrome://extensions` (Load unpacked).
- Do not add analytics, remote code, tracking, or unnecessary permissions.
- Do not add functionality intended to circumvent access controls or service restrictions.
- Only contribute code and assets you have rights to share under the MIT license.
